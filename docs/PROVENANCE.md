# Provenance

The original public repository is https://github.com/Ben-Scr/ConsoleCpp on master.
Migration begins at commit `fea9e49cb9af6ae40aa514dbef4b7fbd70ad2d38`; its history is retained.
Its published package is ConsoleCPP 1.0.3, owned by ben.scr, with seven public static methods.
The source consisted of a small C++ header/implementation, a Visual Studio static-library project,
an example and a prebuilt .lib. It had no third-party runtime dependencies or automated tests.

LICENSE.txt remains the original Ben Schneider author-attribution license, not an MIT substitute.
The original repository and published package versions are preserved. API coverage is listed in
[migration notes](https://github.com/Ben-Scr/BenScr.Console/blob/master/MIGRATION.md).

The shared logo is embedded without resizing or modifying the supplied master:
`branding/BenScr_Icon_Master.png`, RGBA PNG 1254x1254, 795819 bytes, SHA-256
`a5dcabceb766e13c1840a95130ee98a458e12e3713fd9b07f3ceae75a1f5b993`.

Release archives contain the repository commit and exact audited sources. Generated manifests record
the artifact checksum, local consumer results and whether sanitizers ran. Source distribution allows
the consuming compiler to generate native symbols; managed `.snupkg` files do not apply.
